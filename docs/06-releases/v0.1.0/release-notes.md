## 概述

为适配大规模设备接入、控制设备检测周期及数据监控而重新开发的 FOTA 服务器首个版本。本版本实现了完整的设备固件 OTA 管理功能，支持 RBAC 权限体系、产品/设备管理、固件管理、升级策略管理以及系统监控。

---

## 版本更新内容

### 0. 兼容老 FOTA 服务器接口

- 兼容接口：`/fota/version/query`
- 平滑迁移，无缝对接现有设备

### 1. 基于 RBAC 的用户管理系统

- 完善的用户体系：用户、角色、权限三级管理
- 灵活的权限分配：为用户指定角色，精确控制访问范围
- 支持多角色场景，适应复杂组织架构

### 2. 产品管理与设备管理

**产品管理**
- 完善的产品-设备管理机制
- 替代原有按版本过滤的方式，在固件/策略管理中直接选择

**设备管理**
- 设备信息完整展示
- 支持标注测试设备（系统端配置，兼容设备端 dev 属性）
- 多版本展示，直观查看设备升级历史
- 上线时间、最后访问时间等关键信息一目了然

### 3. 固件管理

**存储支持**
- 本地存储
- 兼容 S3 存储

**功能特性**
- 更好的创建表单体验
- 多样化的标签与元数据设置
- 支持占位版本（无包创建），用于版本规划，不可作为升级目标

### 4. 升级策略管理

**策略状态管理**
不再区分测试/生产任务，统一通过状态管理：
- 草稿
- 测试中
- 已验证
- 生产中
- 暂停
- 已过期

**策略配置增强**
- 更多的策略生效条件
- 必须从固件管理中选择版本，杜绝手动输入错误

### 5. 系统监控

**仪表盘**
- 系统级别的可视化仪表盘

**多维度监控**
- 系统级别、区域级别、实例级别的负载监控
- 缓存监控
- 日志实时监控
- 操作日志

**可观测性集成**
- 引入 Prometheus + Grafana
- 支持自定义监控面板

### 6. 多实例部署

- 支持同地区多主机多实例部署
- 跨地区部署需公网或专线（机制待完善）

### 7. 日志架构优化

**架构变更**
- 查询日志存入 ClickHouse（列数据库，高压缩比）
- 消息保留 30 天
- 设备上线时间、最后访问时间、版本信息异步更新回设备表
- 简化业务逻辑，提升数据库承载能力

**变更说明**
- 不再提供查询日志的统一视图
- 专注于大规模设备场景的性能优化
